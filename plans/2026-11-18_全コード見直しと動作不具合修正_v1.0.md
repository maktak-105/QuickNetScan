# QuickNetScan 全コード見直し・動作不具合修正 計画書 v1.0

## 1. 背景・目的
初期実装状態の QuickNetScan において、GUI（`QuickNetScan.exe`）でスキャン開始ボタンを押しても一切動作しない不具合や、停止不能・検出ホストの取りこぼし・Proxy ARPによる誤検出等の問題が存在したため、コード全体を見直して完全動作する状態へ修正する。

## 2. 特定した不具合と修正内容
1. **フロントエンド (`web/static/js/app.js`, `web/static/index.html`, `web/static/css/style.css`, `web/cmd/wasm/main.go`)**:
   - `setScanningState()` 内で存在しない要素 `#detectSubnetBtn` を参照して `TypeError` でクラッシュし、`start_scan` メッセージ送信に到達しない致命的バグを修正。
   - `stopScan()` 関数の二重定義（HTTP用の古い関数によるWebView2用関数の上書き）を削除し、WebView2/HTTP双方で停止が機能するよう統合。
   - `foundHosts.push()` の重複呼び出しを解消し、IPアドレスの数値昇順でテーブル行が挿入されるよう改善。
   - `wasm_exec.js` とローカルのGoコンパイラ（Go 1.27）のバージョン不一致を解消するため、`bundle_wasm.py` で `GOROOT` から `wasm_exec.js` を自動同期する処理を追加。
   - Aboutモーダル内の作者ワッペン寸法を Quick シリーズ共通仕様（`width: 160px; height: auto;`）に統一。
2. **スキャンエンジン (`internal/engine/arp.go`, `port.go`, `scanner.go`)**:
   - `ScanRange()` で発見した稼働ホスト（`LatestHost`）の通知が非ブロッキング `select-default` により破棄されるバグを修正し、検出ホストを確実に全件配信するよう改善。
   - `ScanRange()` の `for` ループ内 `select` の `break` がループを抜けずキャンセルが効かない不具合をラベル付き `break scanLoop` で修正し、`port.go` も `net.Dialer.DialContext` 対応に変更。
   - Windows API `SendARP` の受信用バッファを仕様通り8バイト（`[8]byte`）に修正し、自機ローカルIPのMAC即時解決および別サブネット（オフリンクIP）に対するルーターProxy ARP誤検出防止（`IsLocalSubnetIP` 判定）を追加。
   - スキャン対象指定として標準CIDRに加え、IP範囲（`192.168.1.1-192.168.1.254` / `192.168.1.1-254`）および単一IP指定に対応。
3. **ネイティブWebView2ホスト & ビルド (`src/app/main_gui.cpp`, `QuickNetScan.rc`, `cmd/engine-dll/main.go`, `scripts/build.py`)**:
   - バンドルHTML（`index_embed.html`）から巨大Base64文字列を分離して142KBに軽量化し、`NavigateToString` でメモリから即時ロードする方式に変更。
   - `QuickNetScan.rc` に `index_embed.html`、`app.wasm`、`engine_x64.dll`、`WebView2Loader.dll` をすべてRCDATAとして内包し、外部 `dist/web/` フォルダ不要の自己完結構成を実現。
   - `cmd/engine-dll/main.go` でDLLロード時にサブネット検出をバックグラウンドでプリウォームし、起動直後のUI反映を高速化。
   - `main_gui.cpp` に空白・エスケープ対応のJSONパーサ、スキャンエラー通知、およびネイティブ `IFileSaveDialog` によるCSV保存（UTF-8 BOM付）を実装。
