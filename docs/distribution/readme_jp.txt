--------------------------------------------------------------------------------
動作環境
--------------------------------------------------------------------------------
- Windows 10 (64bit) または Windows 11
- Microsoft Edge WebView2 ランタイム（Windows 10/11 に標準搭載）
- ローカルネットワーク（LAN / Wi-Fi）に接続されたネットワークアダプター

--------------------------------------------------------------------------------
起動方法
--------------------------------------------------------------------------------
ダウンロードした ZIP ファイルを任意のフォルダに展開してください。
QuickNetScan.exe をダブルクリックして起動します。インストーラーや管理者設定は不要です。

--------------------------------------------------------------------------------
基本的な使い方
--------------------------------------------------------------------------------
[GUI版]
1. QuickNetScan.exe を起動します。
2. スキャン対象のIP範囲（例: 192.168.1.0/24）を入力します。
3. ポートスキャンの対象（Web、SSH、RDP、ファイル共有等）を選択します。
4. 「スキャン開始」をクリックすると、Goroutine による並行スキャンが一斉に実行されます。
5. 生きている機器の IP、MACアドレス、開放ポート、応答速度が即座に一覧表示されます。

[CLI版]
コマンドプロンプトや PowerShell から実行します：
  QuickNetScan_cli.exe -range 192.168.1.0/24 -ports 22,80,443,445,3389
